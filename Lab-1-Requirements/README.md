# SE Lab 1 – Requirements Engineering & UML Use-Case Modelling

## Problem Statement #54: Local Sports Tournament & Bracket Manager



This repository contains the deliverables for **Software Engineering Lab 1 – Requirements Engineering & UML Use-Case Modelling**.

The problem statement focuses on a **Local Sports Tournament & Bracket Manager**, a tournament administration platform designed to generate tournament brackets, record live match scores, calculate tiebreakers, and publish updated league standings.

### Target Stakeholders / Actors

- **Team Captain**
- **Tournament Director**
- **Match Official**

### System Functionalities

The system provides the following major functionalities:

1. Generate seeded single/double-elimination tournament brackets based on initial team rankings.
2. Record live match scores.
3. Calculate tiebreakers when required.
4. Update league standings after match results.
5. View the current tournament bracket and standings.

### Requirements

The requirements specification contains:

- **5 Functional Requirements (FR-001 to FR-005)**
- **2 Non-Functional Requirements (NFR-001 and NFR-002)**

Each requirement includes:

- Requirement ID
- Type
- Description
- Priority
- Acceptance Criteria
- Rationale

### UML Use-Case Modelling

The use-case model represents the interaction between the system and its actors.

The model includes:

- System boundary
- Actors
- Primary use cases
- Actor-use-case associations
- `«include»` relationship
- `«extend»` relationship

### Use-Case Flow

The selected core use case is:

**UC-02 – Record Match Score**

The use-case flow specifies:

- Preconditions
- Main Success Scenario
- Alternate Flow
- Postconditions
